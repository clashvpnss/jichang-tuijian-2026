# Clash 推荐：用户挑机场前先核对订阅、格式和信息
更新:2026-11-05 · 依据:开源面板源码、项目文档与发布记录

Clash 推荐先看服务是否提供订阅、返回哪种格式，以及有没有流量到期信息。客户端的版本记录可以另看，不能代替这几项兼容检查。

## 它提供 Clash 订阅吗？

先确认服务是否给出能交给 Clash 客户端读取的订阅。有的服务可能把使用入口限于自家应用，不提供订阅链接。自家应用可用不能直接推出其他客户端也能用。

以开源面板 Xboard 为例，各家机场可能改过，以你那家后台显示为准。下面的格式与信息处理，是这套示例面板的实现。

## 旧格式和 Meta 差在哪？

旧 Clash 与 Clash Meta 的节点输出范围不同。不能把两个名称都简化成 Clash 后，就忽略服务返回的是哪一个格式。

| 输出格式 | 对应节点范围 |
| --- | --- |
| 旧 Clash | ss、vmess、trojan、socks、http |
| Clash Meta | 另有 VLESS、Hysteria2、TUIC |

返回格式由请求里的识别内容参与选择。查看列表时，要连同客户端及取得的格式一起核对，不能只凭缺少节点就给账号状态下判断。

## 流量与到期信息怎么看？

Clash 格式可以通过 `subscription-userinfo` 提供流量和到期信息。它是响应附带的账号资料，客户端可读取后显示。

这一项回答配置有没有带账号信息，与节点协议是否支持不同。对照时把可导入、协议范围、流量到期显示分别记录，不能只确认其中一项。
